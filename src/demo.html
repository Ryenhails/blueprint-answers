1 · Every drawing is read once, into facts

The route is chosen from what the file is, never from where it came from. Each route ends in a table of facts that carry their place on the sheet, so later answers can point at them.

2 · A question climbs only as far as it has to

The cheapest step that can answer wins. A stronger step runs only when the one before it has no answer, and the answer slip shows which steps ran and what each cost.

3 · The model never does what code does better

The model points, code measures

On a scan the model only says where: a spot inside a room, the corners of a zone. Code turns the printed scale and the sheet size into millimetres per pixel, checks it against the scale bar, fills the room out to its walls and returns net area and perimeter.

Counting piece by piece

A whole sheet shrunk to one image hides door swings. The sheet is cut into overlapping tiles, the model boxes the symbol in each, and code merges the boxes. Every counted object is drawn on the sheet.

Reliability comes for free

Answers say how they were produced: computed from geometry, computed from facts read off an image, or read by a model. Where two independent readings exist, agreement between them is shown with the answer.
